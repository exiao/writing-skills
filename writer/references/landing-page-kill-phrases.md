# Landing Page & Stakeholder Page Kill Phrases

Additional kill phrases specific to product pages, stakeholder reports, and marketing landing pages. These supplement the main WRITING-STYLE.md kill phrases.

## Headline patterns to avoid

**Number drop endings in section titles:**
- "Five phases. Three adversarial checkpoints." → rewrite as a single descriptive phrase
- "Three iterations. Zero errors." → lead with the actual data ("68% → 95% citation accuracy")
- "Every number, checked." → use the specific count ("36 of 36 claims traced to source")

The number-drop creates a manufactured cadence that reads as AI-generated on a landing page. Use specific numbers inline instead.

**"Institutional-quality" and similar puffery:**
- Never use "institutional-quality" as a modifier (it's self-congratulatory)
- Never use "world-class", "enterprise-grade", "best-in-class"
- If the quality is genuinely good, the sample output section proves it. Don't claim it in the hero.

## Body copy patterns

**"Treating X as a first-class feature, not an afterthought":**
This is a formulaic contrast ("not X, Y"). Rewrite to state what was built: "So we built verification into the pipeline itself."

**"The system self-corrects: it identifies its own errors...":**
This is an interpretive/setup sentence. State the mechanism: "After each run, the evaluator flags errors. The pipeline patches the skills that caused them and runs again."

## Stakeholder-specific guidance

When the audience is a portfolio manager or fund stakeholder (not a developer):
- Cut: PR counts, commit counts, lines of code, skill lists, data source pills, "what's next" roadmaps
- Keep: sample output they can read themselves, verification tables, accuracy progression, architecture diagrams
- The question they're asking: "Does this work, how good is the output, and can I trust it?"
- Show the work (actual memo excerpt), not the process (engineering changelog)

## Hero subtitle pattern

Don't chain three "Every X" sentences: "Every claim cited. Every number verified. Every case stress-tested."
Instead, use a single sentence with specific mechanism: "An autonomous research agent that writes one-page equity memos with sourced citations, adversarial bear cases, and a built-in fact-checker that catches its own mistakes."
